# 🎮 Neon Tic-Tac-Toe

A modern **Tic-Tac-Toe desktop game** developed using **JavaFX** and **Core Java**.

## 🚀 Features

- 🎮 Two-player Tic-Tac-Toe
- 👤 Custom player names
- ❌ X player
- ⭕ O player
- 🏆 Automatic winner detection
- 🤝 Automatic draw detection
- 💡 Winning-cell highlight
- ✨ Winning-cell pulse animation
- 📊 Scoreboard
- 🔄 Restart Game
- 🗑️ Reset Score
- 🏠 Main Menu
- 🚪 Exit Game
- 🌈 Neon-style user interface

## 🛠️ Technologies Used

- Java
- JavaFX
- Maven
- 2D Arrays
- Event Handling
- IntelliJ IDEA
- Git
- GitHub
